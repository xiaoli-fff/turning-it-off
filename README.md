One funny line from a hopeless tech support agent to a desperate customer: the classic fix, then a conspiratorial offer to pretend the line dropped.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
